# MVP: Sistema de Adoção de Animais - Campo Largo (ODS 15)

##  Sobre o Projeto
Este repositório contém o código-fonte de um **Minimum Viable Product (MVP)** desenvolvido em Python (Flask) com foco na promoção da adoção responsável de animais no município de Campo Largo - PR, alinhado diretamente ao **Objetivo de Desenvolvimento Sustentável 15 (Vida Terrestre)** da ONU.

##  Stack Tecnológica*
 **Backend:** Python / Flask (Arquitetura de 3 camadas)
 **Frontend:** Bootstrap 5.3 (Focado em acessibilidade WCAG AA e design mobile-first)
 **Qualidade e CI/CD:** GitHub Actions (Pipeline automatizado com 88% de cobertura de testes)
